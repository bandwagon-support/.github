**步骤三：新建工单**
点击 `Open New Ticket`，填写以下信息：

## 二、搬瓦工客服能帮你处理哪些问题？

这是很多人搞不清楚的地方。搬瓦工卖的是"无托管型 VPS"（Unmanaged VPS），意思是服务器的系统层面你自己管，他们只负责硬件和网络。

**客服会处理的问题：**

**1. IP 被封/屏蔽问题**
如果你的 VPS IP 在国内被 GFW 封锁，而 KiwiVM 面板里的免费换 IP 次数已经用完（或者不符合免费换 IP 的条件），可以通过工单申请付费更换。付费换 IP 一般是 $8.79。

**2. VPS 无法启动/宕机**
如果你在 KiwiVM 里重启了好几次还是无法连接，排除了你自己操作问题之后，这就是需要联系客服的。

**3. 机房故障/维护相关**
搬瓦工某个机房挂了，波及到你的 VPS，这种情况也可以工单咨询进展。

**4. 付款/账单问题**
付了钱但 VPS 没到账、续费账单有疑问、申请退款等财务类问题。

**5. 账号安全问题**
密码找回、账号被锁定等。

---

**客服通常不管的问题：**

- 你自己搞坏了系统（比如删了关键文件）
- 你的软件配置问题（Nginx、WordPress 报错之类）
- SSH 连不上但其实是你本地的问题
- 怎么搭建某个应用

这类问题属于"用户自己管理"的范畴，客服大概率不会回答。遇到这些，去找社区教程或者在 Telegram 群里问更有效。

## 四、五个提工单的实用小技巧

在和搬瓦工客服打了这么长时间交道之后，这些经验是值得记录下来的：

**1. 时机选择很重要**
温哥华工作时间是北京时间的深夜/凌晨。如果你周五下班前提了个工单，很可能要等到下周一才有真人回复。赶时间的话，就算算好当地工作时间再提。

**2. 描述要清晰，信息给全**
工单里把 VPS 的 IP、出现问题的时间、你已经尝试过的操作都写进去。客服不需要猜，你描述越清楚，回复越快越准。

**3. 不要反复催单**
提交工单之后就别再回复了，每回复一次，工单的时间戳就变新，排序就往后推。真正的等待才是对的选择。

**4. 可以提供截图**
工单系统支持上传附件，截图往往比文字描述效率高，尤其是报错信息。

**5. 退款走工单最干净**
搬瓦工支持 30 天无理由退款，通过工单申请比邮件更有记录，处理也更快。
